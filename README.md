# 🚀 AI-Meeting-Manager-And--Resume-Enhancer

An all-in-one AI-powered productivity suite that analyzes resumes, summarizes meetings from audio/video files, offers tutoring in technical subjects, and assists with code debugging and optimization. Built with Gradio and Google's Gemini AI.

---

## 🌟 Features

### 📄 Resume Analyzer
- Analyzes resumes and job descriptions to:
  - Calculate skills match
  - Highlight missing keywords
  - Suggest improvements
  - Identify key strengths

### 🎥 Meeting Manager
- Supports audio and video file input
- Transcribes and summarizes meeting content
- Extracts:
  - 📌 Key decisions
  - ✅ Action items
  - 💬 Discussion points
  - 🚀 Next steps

### 🎓 AI Tutor
- Supports subjects like Programming, Electronics, Mechanics
- Answers questions with:
  - Core principles
  - Formulas
  - Real-world examples
  - Common mistakes

### 💻 Code Assistant
- Supports Python code
- Tasks: Debug, Optimize, Explain
- Delivers:
  - Optimized solutions
  - Line-by-line explanations
  - Alternatives and tips

---

## 🛠️ Tech Stack

- **Frontend**: [Gradio](https://www.gradio.app/)
- **Backend**: Python 3.x
- **AI Models**: Google Gemini (2.0 Flash)
- **Media Processing**: `moviepy`, `speech_recognition`, `ffmpeg`
- **Concurrency**: `ThreadPoolExecutor`
- **Transcription**: Google Speech Recognition
